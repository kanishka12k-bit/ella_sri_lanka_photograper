
# Documentation: UX Photographer Template

Thank you for purchasing the **UX Photographer** template. This document provides all the necessary information to set up and customize your website.

---

## 1. Introduction
The **UX Photographer** template is a premium, minimalist portfolio website designed specifically for photographers and visual artists. It offers a professional and clean layout to showcase your work, services, and pricing.

---

## 2. File Structure
Your project folder contains the following files and directories:

* `/assets/` - Contains all media, images, and styling resources.
    * `/css/style.css` - Main stylesheet for the template.
    * `/img/` - Image assets used throughout the site.
    * `/js/` - Contains JavaScript files (`main.js`, `portfolio.js`, `contact.js`, `pricing.js`) for functionality.
* `index.html` - Homepage.
* `about.html` - About me page.
* `portfolio.html` - Portfolio gallery page.
* `pricing.html` - Services and pricing page.
* `contact.html` - Contact and booking page.

---

## 3. Getting Started (Installation)
1.  Extract the downloaded ZIP file to your local computer.
2.  Open the project folder in your preferred code editor (e.g., VS Code).
3.  You can view your website locally by opening any `.html` file in your web browser.
4.  No complex backend setup is required; this is a static site.

---

## 4. Customization Guide

### Changing Content
Open any `.html` file in your code editor. You can easily modify the text content (e.g., headings, paragraphs) directly within the HTML tags.

### Changing Images
All images are located in the `/assets/img/` folder.
* To update an image, replace the existing image file with your own, ensuring you keep the **same filename and format** (e.g., `about-1.jpg`).
* Alternatively, update the `src` attribute in the HTML file to point to your new image.

### Customizing Styles (Colors/Fonts)
To modify colors, fonts, or layout, edit the `style.css` file located in `assets/css/`. 
* Find the relevant CSS class and change the `color`, `background-color`, or `font-family` properties.

### JavaScript Functionality
The project uses specific JavaScript files for individual pages (`contact.js`, `portfolio.js`, etc.). If you are familiar with JavaScript, you can modify these files to change interactive behaviors or form handling.
